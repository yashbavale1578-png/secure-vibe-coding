# Security Policy

## Scope

This repository contains defensive secure-development guidance and local repository inspection utilities. It is not intended to facilitate unauthorized access, exploitation, credential theft, persistence, evasion, or disruption.

## Reporting a vulnerability

Do not publish secrets, personal data, exploit payloads against third-party systems, or sensitive proof-of-concept details in a public issue. Use the repository owner's private security reporting channel once configured. Until a private channel is published, contact the maintainers through a trusted private channel.

## Safe use

- Assess only systems you own or are explicitly authorized to test.
- Define target scope and test limits before active testing.
- Never use this skill to access another person's account, data, infrastructure, or service without permission.
- Keep test data synthetic where possible.
- Obtain approval before destructive or production-impacting actions.

## No guarantee

Following this guide does not guarantee security, legal compliance, certification, or freedom from vulnerabilities.
